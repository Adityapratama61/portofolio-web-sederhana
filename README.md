# Website Portofolio Aditya Pratama

Ini adalah proyek website portofolio pribadi untuk Aditya Pratama, seorang Mahasiswa Teknologi Informasi. Website ini berfungsi sebagai "kartu nama" digital untuk menampilkan profil, keterampilan, riwayat pendidikan, proyek-proyek yang telah dikerjakan, dan sertifikat yang dimiliki.

## ✨ Fitur Utama

Website ini dibagi menjadi beberapa bagian utama:

* **Header:** Navigasi utama yang tautannya mengarah ke setiap bagian halaman.
* **Hero Section:** Perkenalan singkat ("Aditya Pratama Information Technology Student"), deskripsi diri, dan tombol untuk mengunduh Resume.
* **Skills & Education:** Menampilkan riwayat pendidikan di Bina Sarana Informatika University dan Sandikta Senior High School. Bagian ini juga menampilkan daftar keterampilan teknis.
* **Recent Projects:** Galeri yang menampilkan 3 proyek terakhir:
    * Health Website
    * Goverment Website
    * Postpaid Electricity Payment Website
* **Certificate:** Menampilkan 3 sertifikat yang relevan:
    * Programming Essentials in Python
    * Fortigate Firewall
    * Sertifikat Pengantar Mindset
* **Contact:** Berisi deskripsi profesional singkat dan tautan untuk terhubung melalui Email, GitHub, LinkedIn, dan WhatsApp.

## 🛠️ Teknologi yang Digunakan

Proyek ini dan proyek-proyek di dalamnya menggunakan teknologi berikut:

* **HTML5**
* **CSS3** (diasumsikan dari `style.css`)
* **JavaScript**
* **PHP**
* **MySQL**
* **Laravel**
* **Flutter**
* **Figma** (untuk desain)
* **Canva** (untuk desain)
* **Laragon** (untuk lingkungan pengembangan)

## 🚀 Cara Menjalankan

1.  **Clone repositori ini:**
    ```bash
    git clone [URL-REPOSITORI-ANDA]
    ```
2.  **Navigasi ke folder:**
    ```bash
    cd [NAMA-FOLDER-PROYEK]
    ```
3.  **Buka di Browser:**
    Cukup klik dua kali file `index.html`, dan halaman web akan terbuka di browser default Anda.
